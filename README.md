## 📌 Overview

AgniDrishti AI is a disaster-management decision-support platform that combines satellite fire detections, real-time weather data, and machine learning to assess wildfire risk and support emergency preparedness.

## ✨ Key Features

- 🌦️ **Live Weather Monitoring** — Open-Meteo API integration.
- 🛰️ **Satellite Fire Detection** — NASA FIRMS data.
- 🤖 **AI Risk Prediction** — Random Forest-based risk classification.
- 🗺️ **GIS Risk Map** — Geographical visualization of wildfire-prone zones.
- 🔥 **Hotspot Analysis** — DBSCAN-based spatial clustering.
- 🚨 **Early Warnings** — Risk-based alerts and notifications.
- 🏘️ **Population Risk Analysis** — Identify potentially vulnerable areas.
- 🧭 **Evacuation Support** — Routes and safe-location information.
- 🎙️ **Multilingual Voice Alerts** — English, Hindi, Marathi, Bengali, Telugu, and Tamil.
- 🧠 **AI Incident Advisory** — Gemini-powered recommendations, if configured.

## 🛠️ Tech Stack

**Frontend:** React, TypeScript  
**Backend:** Node.js, Express.js  
**Machine Learning:** Random Forest, DBSCAN  
**APIs:** Open-Meteo, NASA FIRMS, Gemini  
**Deployment:** Firebase Hosting

## ⚙️ Run Locally

```bash
git clone https://github.com/Aadarsh-123-git/-AgniDrishti-AI-Wildfire-Risk-Intelligence-main-.git
cd -AgniDrishti-AI-Wildfire-Risk-Intelligence-main-
npm install
```

Configure the required environment variables in your `.env` file, then run:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## ⚠️ Disclaimer

AgniDrishti AI is a decision-support prototype. Predictions are not guarantees of wildfire occurrence. Always follow official emergency instructions, and validate evacuation information and translations before real-world use.
